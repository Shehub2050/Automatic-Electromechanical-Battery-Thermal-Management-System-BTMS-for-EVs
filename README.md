
## How to Run

1. Open MATLAB.
2. Set the working directory to the project folder containing `matlab_simulation.m`.
3. Run the main simulation script:
   ```matlab
   matlab_simulation
   ```
4. To run the PID tuning comparison script:
   ```matlab
   pid_tuning_comparison
   ```
